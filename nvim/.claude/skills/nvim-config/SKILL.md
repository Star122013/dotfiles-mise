---
name: nvim-config
description: Methods and tools about config nvim.
---

When writing nvim config, always use these:

1. **lsp and format tools**: Use emmylua_ls when coding, and use stylua formatter to avoid error when stop coding.
2. **nvim website**: When using some options or some nvim basic api, search "https://neovim.io/doc/user" or use nvim builtin help command to get some informations.
3. **plugins**: When adding plugins and editing config, search github and read its readme or explore local plugin folder to find "txt" to learn correct config.
4. **config**: search and explore LazyVim,astronvim for some config and make a config like them.
5. **minimal test**: use minimal config to test config is right or not.

May keep default config, but must keep your code right.
